# Angular 17 Employee Management CRUD (Concept-Wise Prep)

This project is an interview-preparation friendly Angular 17 structure that demonstrates:

1. Angular framework basics
2. Components + module concepts
3. Data binding (interpolation, property, event, two-way)
4. Directives (structural + attribute)
5. Decorators + pipes
6. Services + dependency injection
7. Lifecycle hooks
8. Observable + HttpClient + RxJS patterns
9. TypeScript basics

## Folder Strategy

- `src/app/core` -> singleton services, interceptors, global models, DI tokens
- `src/app/shared` -> reusable directives, pipes, and dumb components
- `src/app/features/employees` -> employee feature with CRUD pages/components/services/models
- `src/app/typescript-basics` -> TypeScript concept files for quick revision
- `src/app/data` -> fake in-memory seed data

> Note: This repository is intentionally well-commented in TypeScript files so learners can understand concepts quickly after cloning.
